# Wireframes

## 0. 문서 목적

각 화면의 기본 레이아웃과 정보 우선순위를 정의해요.

이 문서는 레이아웃과 시각적 우선순위의 기준입니다. 함께 제공되는 PNG는 이 문서를 시각화한 참고 산출물이며, 본문과 불일치할 경우 본문을 기준으로 해요.

이 문서에서는 실제 색상, 폰트, 일러스트 스타일 등 Visual Design은 결정하지 않아요.

다음 항목을 결정하는 것을 목표로 해요.

* 어떤 요소가 어디에 위치하는지
* 어떤 요소가 가장 먼저 보여야 하는지
* 사용자가 어떤 행동을 할 수 있는지
* 상태에 따라 화면이 어떻게 달라지는지
* Overlay가 기존 화면과 어떻게 관계를 맺는지

---

# 1. 공통 원칙

## 1. 돌이 가장 크게 보여야 해요

게임의 중심은 메뉴나 상태 정보가 아니라 돌이에요.

특히 홈에서는 화면을 봤을 때 가장 먼저 돌이 보여야 해요.

```text
작은 UI


      큰 돌


작은 UI
```

에 가까운 구조를 사용해요.

---

## 2. 돌 위쪽에는 충분한 공간을 남겨요

홈에서 돌 머리 위에는 식물이 자라요.

처음에는 작은 새싹일 수 있지만 성장한 식물은 훨씬 큰 영역을 차지할 수 있어요.

따라서 돌을 화면의 정확한 중앙보다 조금 아래쪽에 배치하고, 돌 위쪽에 식물이 성장할 수 있는 충분한 공간을 확보해요.

```text
┌─────────────────────────────┐
│                             │
│                             │
│       식물 성장 공간         │
│                             │
│            🌿               │
│          ┌─────┐            │
│          │ 돌  │            │
│          └─────┘            │
│                             │
└─────────────────────────────┘
```

식물이 커졌을 때 UI와 겹치지 않는 것이 중요해요.

---

## 3. 상단 UI는 최소화해요

상단에는 화면을 이해하는 데 필요한 정보만 배치해요.

홈에서는 돌 이름 정도만 기본적으로 보여주는 방향을 우선해요.

```text
몽돌
```

게임명이나 `HOME` 같은 화면 제목은 표시하지 않아요.

행복, 수분, 햇빛처럼 지속적인 관리를 연상시키는 상태 정보도 보여주지 않아요.

---

## 4. 홈의 행동은 하나의 액션 메뉴에 모아요

홈 하단에 여러 개의 큰 기능 버튼을 나열하지 않아요.

우측 하단에 원형 액션 버튼 하나를 배치해요.

```text
                         ●
```

버튼을 누르면 필요한 행동이 위쪽으로 펼쳐져요.

```text
                    씨앗 심기  ●
                 식물 보관함  ●
                       공유  ●
                            ●
```

기능을 사용하지 않을 때는 화면 대부분을 돌과 식물을 위한 공간으로 남겨요.

---

## 5. 돌 자체가 상호작용 버튼이에요

별도의 `쓰다듬기` 버튼은 만들지 않아요.

홈의 돌 전체가 터치 가능한 영역이에요.

```text
       ┌─────────┐
       │         │
       │   돌    │ ← Touch
       │         │
       └─────────┘
```

사용자가 UI 버튼보다 캐릭터 자체를 직접 만지는 느낌을 우선해요.

---

## 6. Overlay는 목적에 따라 다르게 사용해요

Overlay는 모두 같은 방식으로 만들지 않아요.

### 돌 선택 Overlay

화면 대부분 또는 전체를 덮고 선택한 돌과 이름 입력에 집중해요.

기존 돌 목록은 사실상 인지되지 않을 정도로 가려져야 해요.

### 복귀 보상 Overlay

홈의 맥락을 유지해야 하므로 돌이 뒤에서 느껴질 수 있어요.

### 식물 성장 완료

S03의 화면 상태로 처리해요.

중요한 것은 완성된 식물을 충분히 크게 보여주는 것이에요.

---

# 2. S01. 돌 선택

## 기본 구조

처음에는 돌 3종을 한 화면에서 비교할 수 있도록 보여줘요.

```text
┌─────────────────────────────┐
│                             │
│       같이 지낼 돌을        │
│         골라주세요          │
│                             │
│                             │
│    ○         ○         ○    │
│   돌 A      돌 B      돌 C   │
│                             │
│                             │
│                             │
│                             │
│                             │
└─────────────────────────────┘
```

이 화면에서 이름 입력이나 선택 확정 UI는 보여주지 않아요.

---

## 화면 구성

### 상단 안내

화면의 목적을 짧게 알려줘요.

```text
같이 지낼 돌을
골라주세요
```

제품 설명이나 튜토리얼 문장은 추가하지 않아요.

---

### 돌 선택 영역

돌 3종을 한 화면에서 비교할 수 있게 보여줘요.

```text
    ○         ○         ○
   돌 A      돌 B      돌 C
```

3종뿐이므로 Carousel이나 별도 페이지 이동은 필요하지 않아요.

각 돌 전체가 터치 영역이에요.

---

# 3. S01. 돌 선택 Overlay

돌을 누르면 선택한 돌을 크게 보여주는 Overlay가 열려요.

Overlay는 화면 대부분을 차지해요.

```text
┌─────────────────────────────┐
│                             │
│           뒤로              │
│                             │
│                             │
│                             │
│             ●               │
│            돌 B              │
│                             │
│                             │
│       이름을 지어주세요       │
│                             │
│   ┌─────────────────────┐   │
│   │                     │   │
│   └─────────────────────┘   │
│                             │
│ 이름은 나중에 바꿀 수 없어요. │
│                             │
│       [ 데려가기 ]           │
│                             │
└─────────────────────────────┘
```

뒤의 돌 목록은 사용자의 주의를 끌지 않도록 충분히 가려요.

시스템 Back 또는 X로 Overlay를 닫고 선택을 취소해요. 바깥 영역 터치로는 닫지 않아요.

---

## 확대된 돌

Overlay에서 가장 강하게 보여야 하는 요소예요.

```text
          ●
         돌 B
```

선택한 돌을 충분히 크게 보여줘요.

사용자가

> 이 돌로 할까?

를 다시 한번 느낄 수 있어야 해요.

---

## 이름 입력

돌 아래에 이름 입력 영역을 배치해요.

```text
이름을 지어주세요

┌─────────────────────┐
│                     │
└─────────────────────┘
```

이름 입력은 Form 작성보다 돌에게 이름을 붙이는 행동처럼 느껴져야 해요.

---

## 이름 변경 불가 안내

이름 입력 근처에 짧게 안내해요.

```text
이름은 나중에 바꿀 수 없어요.
```

강한 경고 UI를 사용하지 않아요.

---

## 데려가기

Overlay의 Primary Action이에요.

```text
[ 데려가기 ]
```

이름이 유효할 때만 활성화돼요.

```text
유효한 이름 입력
 ↓
데려가기 활성화
```

누르면 돌과 이름을 함께 확정하고 S02 홈으로 이동해요.

---

## 뒤로가기

다른 돌을 보고 싶을 때 사용해요.

```text
Overlay
 ↓ Back
돌 3종 선택 화면
```

입력 중인 이름은 저장하지 않아요.

---

# 6. 홈 상단

## 돌 이름

좌측 상단에 돌 이름을 표시하는 구조를 우선안으로 해요.

```text
몽돌
```

이름은 정보 표시만 가능해요.

터치 행동은 없어요.

---

## 상단에 두지 않는 정보

다음 정보는 기본 홈에 노출하지 않아요.

```text
행복도
수분
햇빛
관리 게이지
```

현재 보유 씨앗이나 기타 자원 역시 홈의 핵심 정보가 아니므로 필요성이 확인되기 전까지 고정 노출하지 않아요.

---

# 7. 홈의 돌 영역

돌은 화면의 가장 큰 시각 요소예요.

돌 자체는 화면 중앙보다 약간 아래에 배치해요.

```text
│                             │
│                             │
│       식물 성장 영역         │
│                             │
│             🌿              │
│           ┌─────┐           │
│           │ 돌  │           │
│           └─────┘           │
│                             │
```

돌 머리 위 식물은 별도의 화분이나 주변 장식이 아니라 **돌의 머리카락처럼** 보여요.

식물이 크게 자라도 화면 상단 UI와 충돌하지 않아야 해요.

---

## 돌 터치

돌 전체가 터치 영역이에요.

```text
       ┌─────────┐
       │         │
       │   돌    │ ← Touch
       │         │
       └─────────┘
```

터치하면 돌이 짧게 반응해요.

```text
돌 터치
 ↓
움찔 / 흔들림 / 표정 변화
 ↓
짧은 반응
```

화면 이동은 없어요.

---

# 8. 홈의 반응 문구

돌 아래쪽에는 매우 짧은 반응을 보여줄 수 있어요.

```text
오늘도 가만히 있네요.
```

또는

```text
조금 기분이 좋아 보여요.
```

상태 수치를 텍스트로 번역하는 용도가 아니에요.

돌에게 성격이 있는 것처럼 느끼게 하는 보조 요소예요.

---

# 9. 홈 액션 버튼

우측 하단에 원형 버튼 하나를 배치해요.

```text
                         ●
```

기본 상태에서는 이 버튼 하나만 보여요.

화면 하단 전체를 Navigation이나 버튼 영역으로 사용하지 않아요.

---

# 10. 홈 액션 메뉴 확장 상태

원형 버튼을 누르면 액션이 위쪽으로 펼쳐져요.

```text
┌─────────────────────────────┐
│                             │
│  몽돌                       │
│                             │
│                             │
│             🌿              │
│           ┌─────┐           │
│           │ 돌  │           │
│           └─────┘           │
│                             │
│      오늘도 가만히 있네요.    │
│                             │
│                 씨앗 심기 ●  │
│              식물 보관함 ●  │
│                    공유 ●  │
│                         ×   │
└─────────────────────────────┘
```

메뉴는 한 번의 터치로 열 수 있어요.

각 행동 역시 펼친 상태에서 한 번의 추가 터치로 실행할 수 있어요.

확장 메뉴는 시스템 Back, 액션 버튼 재터치, 바깥 영역 터치로 닫혀요. 메뉴 항목을 선택하면 메뉴가 닫힌 후 대상 화면으로 이동해요.

---

## 메뉴 우선순위

기본적인 우선순위는 다음과 같아요.

```text
씨앗 심기
 ↓
식물 보관함
 ↓
공유
```

구체적인 순서나 아이콘은 Visual Design 단계에서 조정할 수 있어요.

---

# 11. 홈 - 변화가 있는 재접속

기본 레이아웃은 그대로 유지해요.

변화하는 것은 돌과 식물의 모습이에요.

```text
┌─────────────────────────────┐
│                             │
│  몽돌                       │
│                             │
│                             │
│           ░░░               │
│         ░  🌿  ░            │
│           ┌─────┐           │
│         ░ │ 돌  │ ░         │
│           └─────┘           │
│                             │
│     몽돌에게 이끼가 생겼어요. │
│                             │
│                         ●   │
│                             │
└─────────────────────────────┘
```

문구보다 실제 변화가 먼저 보여야 해요.

---

# 12. 복귀 보상 Overlay

복귀 보상은 홈의 맥락을 유지해요.

```text
┌─────────────────────────────┐
│  몽돌                       │
│                             │
│             🌿              │
│           ┌─────┐           │
│           │ 돌  │           │
│           └─────┘           │
│                             │
│       ┌───────────────┐     │
│       │               │     │
│       │ 돌아온 보상    │     │
│       │               │     │
│       │     보상       │     │
│       │               │     │
│       │    [ 받기 ]    │     │
│       └───────────────┘     │
│                             │
└─────────────────────────────┘
```

돌 선택 Overlay처럼 화면 전체를 독립된 화면으로 전환하지 않아요.

---

## 노출 순서

```text
홈 표시
 ↓
변화한 돌 확인
 ↓
필요한 경우 짧은 Delay
 ↓
복귀 보상 Overlay
```

# 14. S03 상단

좌측에는 Back을 배치해요.

```text
← 씨앗 심기
```

현재 보유한 기본 씨앗 수량은 필요한 경우 화면 상단 또는 씨앗 주변에 보여줘요.

```text
기본 씨앗 ×N
```

현재 씨앗 종류가 하나뿐이므로 씨앗 종류 선택 UI는 만들지 않아요.

---

# 15. 씨앗

씨앗 이미지는 돌이나 완성 식물과 혼동되지 않아야 해요.

명확한 씨앗 형태를 사용해요.

Low-fi에서는 다음처럼 단순하게 표현할 수 있어요.

```text
       ◉
      씨앗
```

씨앗 하나하나를 개별 인스턴스처럼 보여주지 않아요.

---

# 16. 화분

S03의 중심 오브젝트예요.

```text
       ┌───────┐
       │       │
       │ 화분  │
       │       │
       └───────┘
```

식물은 완전히 성장하기 전까지 화분에서 자라요.

돌 머리 위에서 성장하지 않아요.

---

# 17. 씨앗 심기

화면 하단에 Primary Action을 배치해요.

```text
[ 씨앗 심기 ]
```

누르면 기본 씨앗 하나가 소비되고 화분에서 성장하기 시작해요.

```text
기본 씨앗 ×N
 ↓
씨앗 심기
 ↓
기본 씨앗 ×N
```

식물 종류가 내부적으로 결정된다는 사실은 화면에서 보여주지 않아요.

# 18. S03. 성장 중 상태

```text
│                             │
│                             │
│                             │
└─────────────────────────────┘
```

최종 식물 이름이나 종류는 보여주지 않아요.

## 성장 표현

수분, 햇빛, 행복도 같은 관리 게이지는 사용하지 않아요.

성장은 시각적인 변화로 보여줘요.

```text

 ↓
작은 싹
 ↓
조금 큰 식물
 ↓
완성
```

성장 퍼센트가 꼭 필요하지 않다면 보여주지 않아요.

희귀도나 등급 정보를 강하게 보여주지 않아요.

# 31. 공유

홈의 액션 메뉴에서 공유를 선택하면 별도의 Preview 화면 없이 텍스트와 링크를 OS Share Sheet로 전달해요.

실행 환경이 이미지 파일 공유를 지원한다면 현재 돌 상태를 표현한 이미지를 함께 전달할 수 있어요. 아래 구성은 이 선택적 공유 이미지의 예시이며 기본 공유 기능의 필수 결과물은 아니에요.

```text
┌─────────────────────────────┐
│                             │
│                             │
│            🌷               │
│          ┌─────┐            │
│          │ 돌  │            │
│          └─────┘            │
│                             │
│           몽돌              │
│                             │
│                             │
│       애완돌 키우기           │
│                             │
└─────────────────────────────┘
```

공유 이미지를 제공할 때는 다음 요소를 중심으로 구성해요.

* 돌
* 현재 머리 위 식물
* 돌 이름
* 작은 게임 브랜딩

앱 화면 전체를 그대로 캡처하는 구조는 우선하지 않아요.

이미지 파일을 지원하지 않는 환경에서도 텍스트와 링크 공유는 동작해야 해요. 공유가 끝나거나 취소 또는 실패해도 현재 홈 상태를 유지합니다.

# 34. Wireframe 기준에서의 핵심 원칙

### 홈에 들어왔을 때

기능보다 돌과 머리 위 식물이 먼저 보여야 해요.

### 돌의 위치

돌은 화면 중앙보다 조금 아래쪽에 배치해요.

식물이 크게 자랐을 때 사용할 수 있는 세로 공간을 위쪽에 충분히 확보해요.

### 돌과 상호작용할 때

별도의 쓰다듬기 버튼을 제공하지 않아요.

돌 자체를 누르는 것이 상호작용이에요.

### 홈의 기능에 접근할 때

여러 개의 큰 버튼을 고정 배치하지 않아요.

우측 하단의 액션 버튼 하나를 통해 기능을 펼쳐요.

### 씨앗을 심을 때

사용자는 씨앗을 심을 뿐 어떤 식물이 결정되었는지는 알 수 없어요.

```text
씨앗
 ↓
화분
 ↓
성장
 ↓
완성
 ↓
정체 공개
```

의 순서를 화면에서도 지켜요.

### 성장 중일 때

최종 식물 이름이나 결과를 미리 보여주지 않아요.

수분, 햇빛, 행복도 같은 관리 UI도 추가하지 않아요.

### 식물이 완성되었을 때

처음으로 식물의 최종 모습과 이름을 보여줘요.

완성된 식물을 충분히 크게 보여주는 것이 가장 중요해요.

### 식물을 고를 때

식물 아이콘보다 **내 돌에 적용된 Preview**가 중요해요.

### 씨앗을 볼 때

동일한 종류의 씨앗은 개별 아이템으로 반복해서 보여주지 않아요.

```text
기본 씨앗 ×N
```

처럼 수량으로 관리해요.

현재 씨앗 종류는 기본 씨앗 하나예요.

### Overlay

돌 선택 Overlay는 선택한 돌과 이름 입력에 집중할 수 있도록 화면 대부분을 차지해요.

복귀 보상 Overlay는 홈의 돌이 뒤에서 느껴질 수 있어요.

식물 성장 완료는 S03의 화면 상태로 처리해요.

### 이름

이름은 S01 선택 Overlay에서 입력하고 `데려가기`를 눌렀을 때 확정돼요.

이후에는 변경할 수 없어요.
