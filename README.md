# 돌키우기

Apps in Toss 기반으로 애완돌을 키우는 게임이에요.

> **내가 키운 돌이라서 괜히 귀엽다.**

아무것도 하지 않는 돌을 가끔 바라보고, 내가 없는 동안 생긴 작은 변화를 발견하고, 식물로 꾸미면서 조금씩 **내 돌**이라는 감각을 만들어가는 게임을 생각하고 있어요.

돌은 사용자의 관심을 요구하지 않습니다. 자주 접속하지 않았다고 불이익을 주거나, 돌보지 않았다고 죄책감을 느끼게 만들고 싶지도 않아요.

대신 가끔 생각나서 들어왔을 때 작은 변화가 생겨 있고, 새로운 식물을 얻거나 기존 식물을 바꿔보면서 자연스럽게 애착이 생기는 경험을 만들고 싶습니다.

또한 돌이 일반적인 캐릭터처럼 과하게 움직이거나 감정을 직접 표현하지 않아요.

돌은 최대한 돌답게 있고, 게임은 이 돌을 꽤 진지하게 애완동물처럼 대합니다. 그 과정에서 자연스럽게 생기는 약간의 허무한 웃음도 이 게임의 중요한 분위기예요.

## Documents

제품에 대한 판단이 필요할 때는 아래 문서를 기준으로 봅니다.

* `docs/product/identity.md`

    * 이 게임이 어떤 경험을 만들고 싶은지 정의해요.
* `docs/product/persona.md`

    * 어떤 사용자를 위해 만드는 게임인지 정의합니다.
* `docs/product/actors.md`

    * 게임을 사용하는 상태에 따라 Actor와 원하는 행동을 정의해요.
* `docs/product/principles.md`

    * 기능과 UX를 판단할 때 사용할 원칙과 하지 않을 것을 정리합니다.
* `docs/product/core-loop.md`

    * 사용자가 반복해서 경험하게 될 핵심 흐름을 정의해요.
* `docs/features/`

    * 제품의 정체성과 Core Loop를 실제 기능으로 어떻게 만들지 정리합니다.
* `docs/ux/`

    * 기능을 어떤 화면과 흐름으로 경험하게 할지 정리해요.

기능을 추가할 때는 단순히 재미있어 보이는지를 기준으로 판단하지 않아요.

누구를 위한 기능인지, 어떤 가치를 주는지, 이 게임의 정체성과 맞는지, 더 단순하게 같은 경험을 만들 수는 없는지를 먼저 생각합니다.
